# Readiness report format

Use this layout for the report shown in Step 4 and saved in Step 7. Fill it only with real results from the delegations in this run.

```markdown
# Readiness report: [application name]

Applicant: [full name as given by the user]
Submission date: [date]
Checked on: [today]
Summary: [number] of [number] items Ready

| # | Checklist item | Status | File | Notes |
|---|----------------|--------|------|-------|
| 1 | Passport | Ready | passport-scan.pdf | Expires 2031-04-02, number ends 4821 |
| 2 | Degree certificate | Name mismatch | degree.pdf | Name on degree: "Shehar B." |
| 3 | Bank statement | Missing | | No matching file found |

## Name and date of birth check

List every difference found between documents, or "No differences found".

## What to do next

1. The most urgent action first, for example renewing an expired document.
2. Missing items to scan or request.
3. Unclear files to rescan.

This report was made on your NAS from your own files. Nothing was uploaded or shared. It is a checking aid, not legal or immigration advice.
```

Status words are fixed: Ready, Expiring, Expired, Name mismatch, Unclear, Missing. Show only the last four characters of any document number.
